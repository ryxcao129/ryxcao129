### Featured projects

| Project | What it does | Stack |
|---|---|---|
| [**nba-props-model**](https://github.com/ryxcao129/nba-props-model) | Projects NBA player stats with a LightGBM + heteroscedastic PyTorch ensemble, converts them to over/under probabilities, and flags edges vs. de-vigged sportsbook lines with fractional-Kelly sizing. Walk-forward validated. | Python · LightGBM · PyTorch |
| [**news-sentiment**](https://github.com/ryxcao129/news-sentiment) | Fine-tunes FinBERT on financial headlines, builds a daily per-stock sentiment signal, and tests it with rank IC and a market-neutral long-short backtest. | PyTorch · Transformers · pandas |
| [**breakout-backtest-app**](https://github.com/ryxcao129/breakout-backtest-app) | Local web app for running and comparing breakout/momentum strategy backtests, with Excel-editable configs and auto-generated analysis. | Flask · yfinance · Matplotlib |
| [**hedge-agent**](https://github.com/ryxcao129/hedge-agent) | AI agent that finds and sizes hedges for sportsbook promos from live odds and logs placed bets to Excel. | Claude Agent SDK · Odds API |
| [**swing-edge**](https://github.com/ryxcao129/swing-edge) | In-play pricing lab for tennis, MLB and NBA: fair prices, swing sizes and a live multi-book scanner for arbs and stale lines. | Flask · Python |
| [**polymarket-arb**](https://github.com/ryxcao129/polymarket-arb) | Matches Polymarket markets to sportsbook odds to surface cross-venue pricing gaps. | Flask · Polymarket API |
